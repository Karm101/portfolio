# Certificates

Put certificate images here.

The "View Certificate" button on the portfolio expects this exact file:

- `ccis-innovision-2026.jpg` — CCIS Innovision 2026 Certificate of Participation

If your file is a PNG or PDF instead, either rename/convert it to `.jpg`,
or update the link in `index.html` (search for `ccis-innovision-2026.jpg`).
