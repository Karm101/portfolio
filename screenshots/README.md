# Project Screenshots

Put screenshots of your live apps here so they show at the top of each project
card (like the reference portfolio). The page expects these exact filenames:

- `documon.png` — DocuMon DRMS (https://special-project-im.vercel.app)
- `georisk.png` — Geo-RISK
- `pathfinder.png` — PathFinder AI (https://pathfinder-ai-ebon.vercel.app)
- `wuwa.png` — WuWa Data Bank (https://wuwa-db.vercel.app)

Tip: open each app in your browser at full width and press F12 → Ctrl+Shift+P →
"Capture screenshot" for a clean capture. A ~1280px-wide PNG works best
(the card crops it to 16:9 from the top).

Missing screenshots are fine — the image slot hides itself automatically
until the file exists.
